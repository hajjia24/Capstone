
# TimeBlocker Web App

A productivity app that can be run in the browser or as a Progressive Web Application on mobile and desktop platforms. It allows you to reserve and section out blocks of time to complete tasks, and gives a better visual understanding of how your day is structured. Originally created as my capstone project.
